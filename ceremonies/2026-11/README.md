# 2026-11 CRL Signing Ceremony

The 2026-11 ceremony includes:

* The re-issuance of the two CRLs (from ISRG Root X1 and X2) revoking the
  cross-signs issued in 2025, ensuring that each revocation entry carries a
  reason code of "superseded".
* The re-issuance of two empty CRLs (from Root YE and YR), just to keep our
  CRL timings in sync.

No new keys or certificates are created by this ceremony. All four CRLs carry
CRL number 108, and a next-update of 2027-10-31.
